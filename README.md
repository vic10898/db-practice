# Практическая работа: Проектирование и работа с СУБД

Данный репозиторий содержит решение практических заданий по проектированию, развертыванию, очистке данных и составлению бизнес-запросов для базы данных.

## Структура репозитория

- **`Задание 07.09/1 Вопрос/`**
  - `schema_bd.pdf` — Диаграмма спроектированной структуры базы данных (ER-диаграмма).
- **`Задание 07.09/2 Вопрос/`**
  - `schema.sql` — SQL-скрипт развертывания структуры базы данных (`CREATE TABLE`, `DROP TABLE`, первичные и внешние ключи, ограничения).
- **`Задание 07.09/3 вопрос/`**
  - `Задачи/` — Исходные файлы с аномалиями (`import_partners.csv`, `import_sales.txt`).
  - `cleaned_partners.csv`, `cleaned_products.csv`, `cleaned_deliveries.csv` — Очищенные от аномалий файлы данных.
  - `import_and_check.sql` — SQL-скрипт импорта данных и проверочные запросы `SELECT COUNT(*)`.
- **`Задание 07.09/4 вопрос/`**
  - `queries.sql` — SQL-скрипт с 3 бизнес-запросами для приложения (агрегация с `LEFT JOIN`, транзакция `BEGIN...COMMIT`, детальная история продаж за период).
- **`Задание 14.09/1 Вопрос/`**
  - `discount.py` — Реализация функции расчета индивидуального процента скидки партнера (`calculate_partner_discount`).
  - `test_discount.py` — Модульные тесты (`unittest`) с проверкой всех граничных значений и 100% покрытием.

## Инструкция по развертыванию и запуску

1. **Создание структуры БД:**
   Выполните файл `Задание 07.09/2 Вопрос/schema.sql` в вашей СУБД (PostgreSQL / DBeaver).
2. **Импорт данных и проверка:**
   Выполните файл `Задание 07.09/3 вопрос/import_and_check.sql`.
3. **Запуск бизнес-запросов:**
   Выполните файл `Задание 07.09/4 вопрос/queries.sql`.
4. **Запуск тестов расчета скидок:**
   ```bash
   python3 "Задание 14.09/1 Вопрос/test_discount.py"
   ```
   Или через автопоиск тестов unittest:
   ```bash
   python3 -m unittest discover -s "Задание 14.09/1 Вопрос"
   ```
   Или демонстрационный запуск консольного скрипта:
   ```bash
   python3 "Задание 14.09/1 Вопрос/discount.py"
   ```
