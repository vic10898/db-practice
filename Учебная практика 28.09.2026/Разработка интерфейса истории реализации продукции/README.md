# Задание 1: Разработка интерфейса истории реализации продукции

## Описание задания
Менеджерам компании необходимо видеть, какие объемы продукции и когда реализовал конкретный партнер, чтобы оценивать его эффективность.

В рамках подзадания реализовано:
1. Новое окно `PartnerHistoryWindow` для отображения истории отгрузок контрагента.
2. Строгое соответствие руководству по корпоративному стилю:
   - Цветовая палитра (`#F4F6F9`, `#FFFFFF`, `#2A73C6`, `#111827`, `#6B7280`);
   - Фирменные шрифты `Arial`;
   - Логотип компании (`resources/logo.png`) и иконка окна (`resources/icon.png`);
   - Заголовок окна в формате `"CRM: История реализации продукции — [Название партнера]"`.
3. Переход в окно истории с главной формы `MainWindow`:
   - При выборе партнера в таблице и нажатии кнопки «История продаж» открывается окно с передачей `partner_id`.
   - Если партнер не выбран, приложение отображает диалоговое предупреждение.
4. Оптимизированный SQL-запрос со связыванием таблиц через `JOIN` (`deliveries` и `products`):
   ```sql
   SELECT 
       p.product_name,
       d.quantity,
       d.delivery_date
   FROM deliveries d
   JOIN products p ON d.product_id = p.id
   WHERE d.partner_id = ?
   ORDER BY d.delivery_date DESC;
   ```
5. Таблица `Treeview` со столбцами:
   - **Наименование продукции**
   - **Количество (шт.)**
   - **Дата продажи** (в человекочитаемом формате, например: `28 марта 2026 г.`).
6. Сводная информационная карточка с общим объемом отгрузок и числом операций.

## Структура файлов модуля
- `main_window.py` — Главная форма реестра партнеров с кнопкой «История продаж».
- `partner_history_window.py` — Окно детальной истории отгрузок конкретного партнера.
- `partner_edit_window.py` — Карточка добавления и редактирования партнера.
- `db_manager.py` — Менеджер базы данных SQLite с таблицами `partners`, `deliveries`, `products`, `product_types`, `material_types`.
- `dialogs.py` — Модуль системных диалоговых окон.
- `validators.py` — Валидаторы входных данных.
- `test_history_window.py` — Модульные тесты проверки SQL JOIN и функционала окна истории.
