# Задание 3: Интеграция метода расчета и комплексное тестирование

## Описание задания
Написанный метод расчета материалов внедрен в пользовательский интерфейс CRM-системы и протестирован на устойчивость к некорректным входным данным.

## Выполненные задачи:
1. **Интерфейс калькулятора материалов (`MaterialCalculatorWindow`)**:
   - Выпадающие списки выбора типа продукции и типа сырья, автоматически синхронизированные со справочниками БД;
   - Поля ввода объема партии и геометрических параметров продукции (длина/ширина);
   - Вывод итогового результата расчета крупным шрифтом с форматированием разрядов тысяч (`1 306 ед.`);
   - Детализация расчета: наименования, коэффициенты, нормативный брак.
2. **Интеграция с главной формой (`MainWindow`)**:
   - Добавлена кнопка «Калькулятор материалов» на верхней панели управления;
   - Обеспечено повторное переиспользование окон без дублирования экземпляров (`lift()`).
3. **Отказоустойчивость и комплексная отладка**:
   - При вводе некорректных значений (символы, пустые поля, отрицательные размеры, нулевое количество или несуществующие типы) приложение не «падает»;
   - Метод возвращает `-1`, интерфейс перехватывает его и отображает информативное сообщение пользователю через `AppDialogs.show_error` с описанием причины;
   - Блок вывода результата переводится в статус «Ошибка данных».
4. **Соблюдение правил ТЗ**:
   - Строго не более одной команды на строку;
   - Стандарт именования `snake_case` для функций и переменных, `CamelCase` для классов;
   - Лаконичные комментарии по существу на русском языке.

## Структура файлов
- `material_calculator_window.py` — Окно калькулятора расчета материалов.
- `main_window.py` — Главная форма CRM-системы со связкой всех окон.
- `material_calculator.py` — Ядро алгоритма расчета сырья.
- `partner_history_window.py` — Окно истории реализации продукции.
- `partner_edit_window.py` — Форма добавления/редактирования контрагентов.
- `db_manager.py` — Менеджер базы данных SQLite.
- `dialogs.py` — Модуль системных диалогов.
- `validators.py` — Валидаторы данных.
- `test_integration.py` — Комплексные тесты взаимодействия интерфейса и ядра.
