# Задание 2: Разработка ядра алгоритма расчета материалов

## Описание задания
Необходимо гарантировать точный расчет сырья для производства продукции, исключив ручные ошибки менеджеров при формировании производственных планов и заказов. Метод учитывает геометрические параметры изделия, коэффициенты типов продукции и технологический процент брака используемых материалов.

## Бизнес-логика метода
Входные параметры (5 шт.):
- `product_type_id` (`int`) — идентификатор типа продукции;
- `material_type_id` (`int`) — идентификатор типа материала;
- `quantity` (`int`) — количество единиц продукции;
- `param_1` (`float`) — вещественный положительный параметр продукции (например, длина или ширина);
- `param_2` (`float`) — вещественный положительный параметр продукции (например, высота или толщина).

### Формулы расчета:
1. **Базовый чистый расход на 1 единицу**:
   $$\text{Расход}_{\text{ед}} = \text{param\_1} \times \text{param\_2} \times \text{Коэффициент типа продукции}$$
2. **Общий чистый расход на партию**:
   $$\text{Расход}_{\text{чистый}} = \text{Расход}_{\text{ед}} \times \text{quantity}$$
3. **Итоговый расход с учетом технологического брака**:
   $$\text{Расход}_{\text{итоговый}} = \text{Расход}_{\text{чистый}} \times \left(1 + \frac{\text{Процент брака материала}}{100}\right)$$
4. **Округление**:
   Итоговый результат округляется до целого числа строго в большую сторону (`math.ceil`).

### Отказоустойчивость и обработка ошибок:
Метод возвращает `-1` без падения программы в случаях:
- переданы несуществующие идентификаторы типов в базе данных;
- переданы отрицательные или нулевые геометрические параметры (`param_1 <= 0` или `param_2 <= 0`);
- количество продукции неположительное (`quantity <= 0`);
- переданы невалидные типы данных.
