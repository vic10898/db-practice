# Реализация ядра бизнес-логики (Расчеты и алгоритмы)

## Описание работы
Разработаны алгоритмы бэкенда информационной системы:
1. Алгоритм расчета накопительной индивидуальной скидки партнера на основе суммарных объемов реализации продукции из базы данных.
2. Алгоритм расчета расхода сырья для производства с учетом параметров изделия, коэффициента типа продукции и процента брака сырья.

## Реализованные компоненты
- **`discount_calculator.py`**:
  - `calculate_partner_discount(sales_volume)` — шкала скидок:
    - менее 10 000 шт. — 0%
    - 10 000 – 49 999 шт. — 5%
    - 50 000 – 299 999 шт. — 10%
    - 300 000 шт. и более — 15%
  - `get_partner_discount(partner_id, db_manager)` — агрегация продаж из БД и расчет скидки.
- **`material_calculator.py`**:
  - `calculate_material_requirement(count, product_type_id, material_type_id, param1, param2, db_manager)`
  - Формула: `Расход = ⌈Количество × Параметр1 × Параметр2 × Коэффициент × (1 + Брак / 100)⌉`.
  - Округление строго вверх (`math.ceil`).
  - Строгая обработка ошибок: при отрицательных параметрах или несуществующих ID в БД функция возвращает `-1` без падения программы.
  - Оформление строго по правилу: одна команда на строку.
- **`db_manager.py`**:
  - Менеджер базы данных с поддержкой справочников `product_types`, `material_types` и агрегации истории продаж.
- **`test_discount.py`** и **`test_material_calculator.py`**:
  - Модульные тесты с проверкой граничных условий, математики и обработки ошибок.

## Запуск тестов
```bash
python3 test_discount.py
python3 test_material_calculator.py
```
