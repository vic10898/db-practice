# Автоматизированное тестирование, аудит безопасности и UX

## Описание работы
Финальный этап разработки CRM-системы: проведение стресс-тестов, модульное тестирование алгоритмов, аудит информационной безопасности и оптимизация пользовательского опыта (UX).

## Состав компонентов
1. **Модульные тесты (`test_material_calculation.py`)**:
   - Не менее 5 тест-кейсов на фреймворке `unittest`:
     1. Базовый расчет расхода сырья по формуле технического задания;
     2. Проверка строгого округления вверх (`math.ceil`);
     3. Обработка несуществующего ID типа продукции (возврат `-1`);
     4. Обработка несуществующего ID типа материала (возврат `-1`);
     5. Обработка отрицательных параметров (возврат `-1` вместо падения программы);
     6. Обработка нулевого объема производства (расход 0).
2. **Аудит безопасности (`test_security_audit.py`, `SECURITY_AUDIT.md`)**:
   - Проверка защиты от внедрения SQL-кода во всех точках входа данных;
   - Полная параметризация запросов с использованием плейсхолдеров `?`;
   - Тестирование на атаки тавтологии (`' OR '1'='1`), деструктивных запросов (`DROP TABLE`) и экранирование спецсимволов.
3. **Обработка исключений и UX-уведомления (`dialogs.py`, `partner_edit_window.py`)**:
   - Перехват исключений базы данных и валидации с выводом информативных диалогов `MessageBox`;
   - Предупреждение о неотвратимости потери несохраненных данных при нажатии кнопки «Назад»;
   - Лаконичные поясняющие комментарии на русском языке в ключевых местах алгоритмов.

## Запуск тестов
```bash
# Запуск модульных тестов расчета материалов
python3 test_material_calculation.py

# Запуск тестов аудита безопасности
python3 test_security_audit.py
```
