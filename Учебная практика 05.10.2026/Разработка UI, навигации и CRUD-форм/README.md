# Разработка UI, навигации и CRUD-форм

## Описание работы
Разработан полноценный графический интерфейс (GUI) на базе `Tkinter` / `ttk` с соблюдением корпоративного стиля:
- Главное окно реестра партнеров `MainWindow`;
- Карточка добавления/редактирования контрагента `PartnerEditWindow`;
- Окно просмотра истории реализации продукции `PartnerHistoryWindow`;
- Окно встроенного калькулятора сырья `MaterialCalculatorWindow`.

## Особенности реализации
1. **Главная форма (`MainWindow`)**:
   - Отображение таблицы с сортировкой и подгрузкой данных из базы (ID, тип, наименование, рейтинг, скидка, email, телефон).
   - Фирменный логотип и иконка приложения.
   - Панель быстрого поиска с безопасной параметризацией SQL-запросов.
   - Двустороннее связывание: автоматическая перерисовка таблицы при сохранении или добавлении партнера без перезапуска приложения.
2. **Форма редактирования (`PartnerEditWindow`)**:
   - Поля ввода: Наименование, выпадающий список (ComboBox) типа партнера, рейтинг (целое число от 0), адрес, директор, телефон, Email, ИНН.
   - Визуальные подсказки (плейсхолдеры) для всех полей.
   - Кнопка «Назад» с контролем несохраненных данных (при наличии изменений вызывается диалог подтверждения выхода).
   - Строгая валидация полей через модуль `validators.py`.
3. **Форма истории реализации (`PartnerHistoryWindow`)**:
   - Детальная таблица поставок конкретного партнера (товар, дата, количество, сумма).
   - Информационная сводка с текущим объемом отгрузок и накопительной скидкой.
   - Кнопка «Назад» для возврата к реестру без потери контекста.
4. **Синхронизация с базой данных (`db_manager.py`)**:
   - Полный цикл CRUD-операций (`INSERT`, `SELECT`, `UPDATE`, `DELETE`).
   - Поддержка ссылочной целостности и каскадного удаления (`ON DELETE CASCADE`).

## Запуск приложения и тестов
```bash
# Запуск графического интерфейса
python3 main_window.py

# Запуск тестов CRUD-операций
python3 test_crud.py
```
