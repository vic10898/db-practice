# Задание 3. Интеграция формы с БД (CRUD-операции и обновление UI)

## Описание
Реализована полноценная интеграция экранной формы карточки партнера с базой данных:
- **Режим добавления**: открытие пустой карточки (заголовок `"CRM: Карточка партнера [Создание]"`), отправка запроса `INSERT`, автоматическое закрытие окна и мгновенное обновление таблицы на главной форме.
- **Режим редактирования**: открытие по двойному клику на запись (заголовок `"CRM: Карточка партнера [Редактирование]"`), автоматическая загрузка актуальных сведений из базы (`SELECT`), выполнение запроса `UPDATE`, закрытие окна и обновление данных в реестре.
- **Ссылочная целостность**:
  - Контроль уникальности контактных данных (Email).
  - Проверка существования записи перед изменением.
  - Транзакционность операций (`commit` / `rollback`).
  - Сохранение связей с историей поставок/продаж (`deliveries`) и динамический расчет накопительной скидки.

## Структура файлов
- `db_manager.py` — Модуль работы с БД (CRUD, транзакции, проверка ссылочной целостности).
- `partner_edit_window.py` — Форма с поддержкой режимов добавления и редактирования.
- `main_window.py` — Главное окно с таблицей партнеров и автообновлением.
- `test_crud.py` — Модульные тесты проверки добавления, чтения, редактирования и защиты целостности.
