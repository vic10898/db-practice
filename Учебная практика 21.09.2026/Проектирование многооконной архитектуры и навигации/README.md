# Задание 1. Проектирование многооконной архитектуры и навигации

## Описание
В рамках задания реализован переход от одностраничного приложения к многооконной архитектуре без потери состояния и риска аварийных завершений:
- Главная форма со списком партнеров (`MainWindow`): заголовок `"CRM: Реестр партнеров"`.
- Форма создания/редактирования партнера (`PartnerEditWindow`):
  - Режим добавления нового партнера: заголовок `"CRM: Карточка партнера [Создание]"`.
  - Режим редактирования существующего партнера: заголовок `"CRM: Карточка партнера [Редактирование]"`.
- Переход по кнопке «+ Добавить партнера» и возврат по кнопке «Назад» / закрытию окна без утечек ресурсов.

## Структура файлов
- `main_window.py` — Главная форма реестра с вызовом карточки.
- `partner_edit_window.py` — Карточка партнера с кнопкой возврата и динамическим заголовком.
- `test_navigation.py` — Модульные тесты переходов и заголовков.

## Запуск приложения
```bash

```
