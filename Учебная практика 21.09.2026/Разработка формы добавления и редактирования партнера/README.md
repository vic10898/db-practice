# Задание 2. Разработка формы добавления/редактирования партнера

## Описание
Разработан графический интерфейс карточки партнера (`PartnerEditWindow`), полностью соответствующий бизнес-требованиям ТЗ:
1. **Наименование компании** — текстовое поле ввода.
2. **Тип партнера** — строго выпадающий список (`ttk.Combobox`) с фиксированными значениями: ЗАО, ООО, ИП, ПАО, ОАО.
3. **Рейтинг** — числовое поле для ввода целого неотрицательного числа.
4. **Адрес** — текстовое поле ввода фактического/юридического адреса.
5. **ФИО директора** — текстовое поле ввода руководителя.
6. **Телефон компании** — поле с маской/плейсхолдером `+7 (999) 000-00-00` и всплывающей подсказкой ToolTip.
7. **Email компании** — обязательное поле с плейсхолдером `info@company.ru` и всплывающей подсказкой ToolTip.

В коде реализованы лаконичные комментарии только в неочевидных местах (инициализация выпадающего списка, автозаполнение при передаче ID партнера, логика плейсхолдеров).

## Структура файлов
- `partner_edit_window.py` — Форма карточки партнера со всеми полями, масками и подсказками.
- `tooltips.py` — Модуль всплывающих подсказок `ToolTip`.
- `main_window.py` — Экран реестра для демонстрации работы формы в обоих режимах.
- `test_form.py` — Модульные тесты проверки полей, типов и подгрузки данных.
