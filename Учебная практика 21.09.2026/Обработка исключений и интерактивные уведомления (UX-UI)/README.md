# Задание 4. Обработка исключений и интерактивные уведомления (UX/UI)

## Описание
В рамках задания реализована комплексная защита приложения от сбоев ввода и взаимодействия с СУБД, а также интерактивная обратная связь через системные диалоговые окна (MessageBox):

1. **Валидация перед отправкой в БД (`try...except`)**:
   - Рейтинг: строго целое неотрицательное число (значения < 0, дробные числа и знаки препинания блокируются с выводом понятной инструкции).
   - Обязательные поля: наименование организации и контактный email не могут быть пустыми. Дополнительно валидируется синтаксис email.

2. **Три типа диалоговых окон (MessageBox)**:
   - **Ошибка (Error)**: выводится при ошибке валидации данных или сбое подключения к СУБД. Содержит заголовок, пиктограмму крестика (`icon='error'`), понятный текст проблемы и точный порядок действий для исправления.
   - **Предупреждение (Warning)**: выводится при нажатии кнопки «Назад» или «Отмена», если пользователь изменил хотя бы одно поле формы. Содержит заголовок, пиктограмму восклицательного знака (`icon='warning'`) и запрос подтверждения безвозвратной потери данных.
   - **Информация (Information)**: выводится при успешном добавлении нового партнера или сохранении изменений в базе данных. Содержит заголовок, инфо-пиктограмму (`icon='info'`) и текст подтверждения.

## Структура файлов
- `validators.py` — Модуль проверки данных и класс исключения `ValidationError`.
- `dialogs.py` — Модуль вызова диалоговых окон (`Error`, `Warning`, `Information`).
- `db_manager.py` — Слой доступа к данным с обработкой исключений `DatabaseConnectionError` и `DatabaseIntegrityError`.
- `partner_edit_window.py` — Экранная карточка партнера с отслеживанием изменений и выводом диалоговых окон.
- `main_window.py` — Главная форма CRM с обработкой исключений подключения к СУБД.
- `test_error_handling.py` — Модульные тесты проверки всех сценариев валидации и предупреждений.
